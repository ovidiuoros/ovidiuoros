My bachelor's thesis, **[ADSTA](https://github.com/ovidiuoros/adsta-azure-security-testing)** (graded 9.60/10), answers a simple question: *how much do basic security measures actually protect a web app?*
 
It sets up an isolated lab in Azure with one attacker and two identical targets, one **vulnerable** and one **hardened**, then runs the same attacks against both and compares the results:
 
- 🏗️ **Terraform** builds the network and VMs, **Packer** prepares the Kali attack machine, **Ansible** configures the Windows targets
- 🐍 **ADSTA**, my Python app, launches Brute Force, SQL Injection, Command Injection and XSS attacks against **[DVWA](https://github.com/digininja/DVWA)** (Damn Vulnerable Web Application), plus Nmap/Netcat recon
- 📊 **Result:** all four attacks succeed on the vulnerable target and are blocked on the hardened one

🚗 **[AI_CAOS](https://github.com/ovidiuoros/AI_CAOS)** · AI Driver Monitoring Assistant, built in a team of 4 at the **CodeLap Hackathon 2026** (AI Drive track, **Porsche Engineering Romania**).
 
A laptop webcam watches the driver and detects fatigue and distraction live. A **local LLM copilot** turns the alerts into spoken warnings and safe car actions, with every proposal checked by code.
 
**My part: the vision module and the presentation**
- 👤 **Driver recognition and profiles:** OpenCV SFace face recognition; each driver gets a personal profile and a **personal calibration** (head pose, eye and yawn thresholds, gaze zones)
- 😴 **Fatigue and distraction:** microsleep, slow blinking, yawning, head drop, gaze off the road and phone use, with **MediaPipe** face and hand landmarks and **YOLO**
- 👓 **Glasses detection:** warns when a driver whose profile requires glasses isn't wearing them, and avoids false microsleep alerts behind sunglasses
